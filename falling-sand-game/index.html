How a Falling Sand Game Works

This falling sand game is a cellular automaton. The canvas is a grid of tiny cells, each holding one material. Every frame, each cell looks at its neighbours and follows a short rule. Nothing is scripted: sand piles up, water finds its level and fire spreads only because of those rules.

Because each particle is just a grid cell, you can simulate thousands at once on a phone. If you want solid objects that collide and bounce instead, try the 2D physics sandbox; for planets and orbits, the gravity simulator sandbox.

// sand: fall, else slide diagonally
if (isFree(x, y + 1))            move(x, y, x, y + 1);
else if (isFree(x - s, y + 1))   move(x, y, x - s, y + 1);
else if (isFree(x + s, y + 1))   move(x, y, x + s, y + 1);
// s = -1 or +1, chosen at random so piles stay symmetric

Sand piles

Sand slides off the sides of a pile until it settles into a slope. Real piles do the same at the “angle of repose”.

Flowing water

Water falls, then spreads sideways until it is level. Sand sinks through it because it swaps places with the water.

Fire and smoke

Flames rise, ignite wood next to them and release smoke. Water puts fire out and turns it into steam-like smoke.

Stone and wood

Stone is a permanent wall for building containers and ramps. Wood stays put until fire reaches it.

Falling Sand Game FAQ

The screen is a grid of cells and each cell holds one material. Every frame, each cell follows a small rule based on its neighbours: sand falls straight down if the cell below is empty, otherwise it slides diagonally. Piles, flowing water and spreading fire all emerge from these simple rules. This technique is called a cellular automaton.
