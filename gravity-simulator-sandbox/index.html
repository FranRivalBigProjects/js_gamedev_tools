How a Gravity Simulator Works

This gravity simulator sandbox runs Newton’s law of universal gravitation on every pair of bodies, every frame. There are no scripted orbits: a planet circles a star only because its sideways speed is just right to keep missing it. Change the speed, mass or gravity strength and the path changes with it.

Each frame the code sums the pull from all other bodies, updates velocity, then moves the body. A small softening term stops two bodies passing through each other from producing infinite force. For a flat, falling-objects version with floors and bouncing, try the 2D physics sandbox.

// acceleration of body a from every other body b
for (const b of bodies) {
  if (a === b) continue;
  const dx = b.x - a.x, dy = b.y - a.y;
  const d2 = dx*dx + dy*dy + SOFTENING;
  const f  = G * b.mass / (d2 * Math.sqrt(d2));
  a.ax += dx * f;
  a.ay += dy * f;
}
a.vx += a.ax * dt;  a.vy += a.ay * dt;   // update velocity
a.x  += a.vx * dt;  a.y  += a.vy * dt;   // then position

Orbital speed

A circular orbit needs v = √(G·M / r). Slower and the planet falls inward; faster and the orbit stretches into an ellipse, then escapes.

Gravity slingshot

Fly a light body close to a heavy moving one and it steals speed. Spacecraft use this trick to reach the outer planets.

The three-body problem

Two bodies orbit predictably. Add a third and the motion becomes chaotic. Load the three-body scenario and watch it unravel.

Merging collisions

With Merge on, touching bodies combine and keep their total momentum. Turn it off to let them pass through each other.

Gravity Simulator Sandbox FAQ

Every body pulls on every other body with a force proportional to the product of their masses and inversely proportional to the square of the distance between them. Each frame the simulator adds up those pulls, updates each body’s velocity, then moves it. Orbits, slingshots and collisions emerge from that single rule.
